# Security Policy

Security updates and critical bug fixes are provided for the following releases:

| Version | Supported          |
| :---    | :---:              |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability in Glypr, please report it privately rather than opening a public issue.

### How to Report:
- **Email:** Send details to `213238+phrozen@users.noreply.github.com` or create a private security advisory through the GitHub repository interface.
- **Details to Include:**
  - Description of the vulnerability and affected components.
  - Steps or a minimal proof-of-concept to reproduce the behavior.
  - Potential impact on users or host environments.

### Response Timeline:
- **Acknowledgment:** Within 48 hours of initial receipt.
- **Triage & Status Update:** Within 5 business days.
- **Coordinated Disclosure:** We will work with you to patch the issue and publish an advisory alongside a release.
